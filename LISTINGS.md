## Tier 1 — Core registries (verified live, July 2026)

### 1–3. The DanceCal family: BluesCal + FusionCal + DanceCal (one submission)

- **What:** Dave Madison's calendar network — the de-facto global registries for the target scenes. BluesCal is the primary dedicated blues event calendar; FusionCal the dedicated fusion one; DanceCal the umbrella (filters: Blues, Lindy, Balboa, Solo Jazz, Fusion — exactly our scope, no salsa/tango/ballroom).
- **Reach:** Worldwide with dense Europe coverage. BluesCal has European events through Oct–Nov 2026 (Hasselt, Brno, Bern, Porto, Lithuania) and currently **zero Poland events** — we'd be the only one. FusionCal lists Berlin, Turin, Barcelona, Bruges, Newcastle into 2027. DanceCal lists Herräng and Kraków events.
- **How:** Self-serve form at [bluescal.com/Submit/](https://bluescal.com/Submit/) (or /Submit/ on any of the three — the form header says "Submit a new event for DanceCal/BluesCal/FusionCal/BalCal", so **one submission feeds all of them** via the Dances checkboxes). No account needed. Moderator approves before it appears; "Submitting multiple times will not help!"
- **Fields:** Event Name, City, Country, Date, Type (Workshop / Exchange / House Party → use Exchange), Dances checkboxes (tick Blues + Fusion), Email. URL / Facebook / description optional.
- **Eligibility:** "Local events, non-social-dancing events and one-day events do not belong here and will not get approved." A 5-day international festival qualifies comfortably.
- **Cost:** Free (no fee mentioned anywhere).

### 4. SwingPlanIt — swingplanit.com

- **What:** The most comprehensive worldwide swing festival directory; the first place travelling swing dancers look.
- **Reach:** Global. Blues is a first-class submittable style (alongside Balboa, Boogie Woogie, Charleston, Jazz, Lindy Hop, Shag) and is actively used: 2026 European blues listings include Mainhatten Blues (Frankfurt), Blues Remix (Brussels), Paris Midnight Blues, Boulevard Blues (Hasselt), Blues Dose Retreat (CZ). No Fusion category — list under Blues.
- **How:** Free self-serve form at [swingplanit.com/index.php/swing-event-submission](https://www.swingplanit.com/index.php/swing-event-submission). No account; there's a small math captcha.
- **Fields:** name, dates, website URL, country, town, contact, event type (Camp / Weekender / Exchange only — no weekly socials; use Camp), description, teachers, style checkboxes.
- **Constraints:** description must NOT contain web links, teacher names, booking prices, or venue addresses (separate fields exist). Incomplete submissions are silently not published.
- **Lead time:** site updates once a week — allow 7 days; resubmitting doesn't speed it up. Submit early.
- **Cost:** Free.

### 5. swingfestivals.com

- **What:** Worldwide swing festival directory, 240+ festivals across 38 countries, listings May 2026 → April 2027.
- **Reach:** Global; Blues is a first-class style filter with real 2026 blues listings (Slow Flow Madrid, The Slow Down Brno, Summertime Blues Herchen, swingomania Nuremberg).
- **How:** **Email only** — there is no submission form, and the footer /contact link 404s (as do /submit, /add-event, /list-your-festival). The working route is the mailto CTA on [/about](https://www.swingfestivals.com/about): **hello@swingfestivals.com** ("If you organise a swing festival... get in touch. It's free and reaches the whole community.").
- **Cost:** Free (explicitly stated).
- **Note:** actively maintained (forward calendar to Apr 2027) though their blog is stale — judge by the calendar, not the blog.

### 6. Swing Calendar — swingcalendar.com

- **What:** Worldwide swing event directory, actively developed (platform release notes as recent as 2026-06-29), ad-tracker free.
- **Reach:** ~250–400 event pages with dates from Jul 2026 into 2027–28; genuine blues and Central-Europe coverage: Berlin Blues & Fusion Experience (Oct 2026), Prague Spring Swing Festival, Blues Workshop Weekend Magdeburg, Mainhatten Blues Frankfurt — 17 blues/fusion-named events total. Blues is a first-class subtype.
- **How:** Self-serve but **account-gated**: register a user account with the "Organizer" role, then + Create → fill details, upload photos, submit. Moderated review with email confirmation before publication.
- **Cost:** Free (explicit). Paid upsells (featured placement, ticketing) exist but don't gate a basic listing — ignore them.

### 7. fusion-dancing.eu

- **What:** THE Europe-specific fusion dance calendar, and the most Central-Europe-relevant venue found: it maps ~40 local scenes including Kraków, Warszawa, Praha, Wien, Berlin. ICS/WebCal/RSS feeds extend its reach.
- **How (three routes, all free):**
  1. **Discord** (preferred): the European Fusion Dancing Discord — `discord.gg/28ej3V2vQG` — events added there are auto-proposed to the site (pipeline confirmed live via automated GitHub commits).

- **Eligibility (the one real hurdle):** events must be multi-day AND "dedicate at least roughly half their resources to Fusion dancing" — single-evening socials get pointed to local scene pages. Open Blues qualifies on duration; the fusion share is honestly fuzzy because the program is crowdsourced. Submitted 12 Jul via the email route; whether it meets their bar is now the moderators' call.
- **Maintained:** merged event PRs dated 2026-07-05 to -08; calendar lists 2026–27 events including Berlin Blues & Fusion Experience.
