# Open Blues 2027 — listings tracker

This file tracks distribution. Copy, facts, images and operator rules live in
[`LAUNCH-KIT.md`](LAUNCH-KIT.md); do not create another copy bank here.

The 2027 dates are confirmed: **2–6 September 2027** at Piotrowice Nyskie Palace.

## Status language

- `TODO` — no 2027 submission is recorded in this repository.
- `VERIFY` — check the existing public record before submitting, to avoid a duplicate.
- `SUBMITTED` — a 2027 submission was sent; record the date and route in the log.
- `LIVE` — the 2027 listing was opened and checked; add the public URL to the log.
- `BLOCKED` — the next action needs an account, owner or decision that the operator does not have.
- `SKIP` — deliberately excluded; record why.

The reset below was made on 2 September 2026. Old 2026 submissions do **not** count as 2027
progress. Change a row only after observing the 2027 action or public result yourself.
